# Autoresearch-ai

**AutoResearch Scientist AI** is a modern AI-powered research platform with a futuristic operating system-style interface. The project now includes a modular React + TypeScript + Tailwind frontend and an Express + TypeScript backend designed for future LLM, RAG, OCR, AI-agent, and MongoDB integrations.

## Experience included

- Secure authentication entry experience
- Real-time style dashboard with research KPIs
- File upload system for future ingestion pipelines
- AI chat workspace for guided research prompts
- Researcher profile and activity history
- Research Universe mapping view
- Memory Chamber for durable findings
- Research Gap Lab for opportunity framing
- Presentation Studio for executive-ready narratives

## Tech stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Express, TypeScript, Multer, CORS
- **Architecture:** Modular frontend services/components and backend route modules for future integrations

## Getting started

```bash
npm install
npm run dev
```

This starts the frontend on `http://localhost:5173` and the backend on `http://localhost:3001`.

## Validation

```bash
npm run lint
npm run test
npm run build
```
